Title: Detect actual model dtype before setting bf16/fp16 flags

Summary:
- Examine the loaded model's parameter dtype; only enable bf16 if tensors are bfloat16, otherwise fall back to fp16 when the weights are float16.
- Warn the user when a bf16 request is downgraded to fp16 to avoid Unsloth precision mismatches.
